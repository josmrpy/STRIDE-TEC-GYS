# Convenciones del curso

Estas convenciones fueron indicadas por la profesora Laura Coto Sarmiento. Aunque difieren de las convenciones habituales de Python, deben seguirse en las actividades.

- Usar `camelCase` para los nombres.
- Elegir nombres descriptivos.
- No dejar líneas en blanco en el código.
- No mezclar idiomas; evitar el spanglish.

## Estructura del programa

Organizar el código como una redacción, con estas tres partes:

1. **Introducción:** indicar quién elaboró el código, las fechas y horas de creación y finalización, y la versión de Python utilizada.
2. **Desarrollo:** definir aquí todas las funciones. Iniciar esta sección con el comentario `# Definición de funciones`.
3. **Conclusión:** incluir aquí el programa principal e iniciar esta sección con el comentario `# Programa principal`.
